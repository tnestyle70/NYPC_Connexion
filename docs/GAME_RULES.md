# Connexion 공식 규칙 (NYPC 2025 Code Battle 결승 1경기)

출처: <https://nypc.github.io/2025-codebattle/finals_1>
검증: `Log/WebSiteBot/2026-06-11_sampleai_p1human_196-304.log`를 `scripts/analyze_game.py`로
리플레이하여 최종 점수 196/304를 정확히 재현함. 규칙 페이지의 연결 예시
(`c5-` ~ {`c5+`,`b5+`,`c4+`}, `f4+` ~ {`f4-`,`f5-`})도 코드 출력과 일치.

## 보드

- 좌표: 열 `a`~`f`(왼쪽→오른쪽) × 행 `1`~`6`(아래→위) × 접미 `+`/`-`.
- 72개 라벨 중 8칸 제외: `a1-`, `a4-`, `c3+`, `c6+`, `d1-`, `d4-`, `f3+`, `f6+` → 칸 64개.
- 연결 정의 (공식):
  - `(c,r,-)` ~ `(c,r,+)` (같은 칸 짝), `(c-1,r,+)` (왼쪽 열 같은 행), `(c,r-1,+)` (같은 열 아랫 행)
  - 대칭으로 `(c,r,+)` ~ `(c,r,-)`, `(c+1,r,-)`, `(c,r+1,-)`
- 즉 차수 ≤ 3의 허니콤(벌집) 그래프. 실측 차수 분포: 차수2 = 32칸, 차수3 = 32칸.
- 구조 특기사항:
  - 각 행은 `a-`–`a+`–`b-`–`b+`–…–`f-`–`f+` 순의 가로 사슬, 행 사이는 `(c,r,+)`~`(c,r+1,-)` 대각 연결.
  - 열 `b`, `e`만 제외 칸 없이 12칸 지그재그 경로가 통째로 살아 있다 (프리미엄 통로).
  - 열 `a`,`d`는 행 1·4의 `-`가, 열 `c`,`f`는 행 3·6의 `+`가 빠져 통로가 끊겨 있다.

## 타일

- 색 4종 (`R`,`G`,`B`,`Y`) × 문양 4종 (`1`~`4`) = 16종 × 각 4장 = 총 64장.
- 표기 = 색+문양 (예: `G2`). `X0` = 타일 없음.

## 진행

1. 각자 5장씩 손패를 받고 시작 (총 10장 공개).
2. 선공부터 교대로 총 64수. 자기 차례에:
   - 손패에서 타일 1장을 **빈 칸 아무 곳에나** 배치 (배치 제약 없음).
   - 주머니에서 1장 뽑아 손패 보충. 뽑기는 **비복원 균등 추출** (각주 1).
3. 주머니 = 64 − 10 = 54장 → 55수째부터 뽑을 타일이 없어 `X0`.
4. 64수가 끝나면 보드가 가득 차고 게임 종료, 점수 계산은 이때 1회.

## 점수

- **선공(1P) = 문양 기준, 후공(2P) = 색 기준.**
- 간접 연결 (각주 2): 자기 자신 포함, "연결"의 반사·추이적 폐포 = 연결 성분.
- 점수 = 같은 속성으로 이어진 **각 연결 성분에 대해 (성분 크기)²의 합**.
  - 동치 표현: 각 타일이 "같은 속성으로 간접 연결된 타일 수(자신 포함)"만큼 점수를 받음.
  - 외톨이 타일도 1²=1점.

## 정보 구조 (봇 설계상 중요)

- 공개 정보: 보드 전체, **양쪽 손패 전부** (`INIT`이 둘 다 제공, 이후 `GET`/`OPP`가 모든 획득을 공개),
  남은 주머니의 구성(전체 64장 − 보드 − 양쪽 손패로 유도 가능).
- 비공개 정보: 주머니에서 **무엇이 언제 나올지(순서)** 뿐.
- 결론: hidden information 게임이 아니라 **확률적 완전정보 게임** (backgammon류).
  belief 모델링 불필요. 찬스 노드 = 균등 뽑기. 주머니가 비는 55수 이후는 완전 결정론
  → 정확한 종반 풀이(exact endgame) 가능 구간.

## I/O 프로토콜 (봇 ↔ 심판)

| 명령 | 형식 | 응답/의미 |
|---|---|---|
| READY | `READY (FIRST\|SECOND)` | 3,000ms 내 `OK` 출력 |
| INIT | `INIT A1..A5 B1..B5` | 내 초기 손패 5장 + 상대 초기 손패 5장 |
| TIME | `TIME t1 t2` | t1 ms 내에 `PUT p T` 출력 (p=칸, T=타일) |
| GET | `GET T` | 내가 뽑은 타일 T (`X0` = 없음) |
| OPP | `OPP p T1 T2 t` | 상대가 p에 T1 배치, T2 획득, t = 시간 정보 |
| FINISH | `FINISH` | 게임 종료 |

- 시간 초과(TLE) 시 해당 게임 실격패.
- 웹사이트 리플레이 로그 형식 (프로토콜과 별개):
  `INIT <선공5장> <후공5장>` / `FIRST|SECOND <칸> <배치타일> <획득타일> <t>` /
  `SCOREFIRST n` / `SCORESECOND n`.
